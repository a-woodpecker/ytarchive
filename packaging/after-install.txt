YT Archive needs two external tools to do its work:

  yt-dlp   - talks to YouTube
  ffmpeg   - merges the separate video and audio streams

Neither is bundled, so that each can be updated independently. yt-dlp in
particular needs updating often, because YouTube changes frequently.

In a Command Prompt:

  winget install -e --id Gyan.FFmpeg
  pip install -U yt-dlp

Install yt-dlp with pip rather than winget. The winget package carries its own
bundled Python, and the plugins needed for age-restricted videos and for signing
media URLs can then never be found - pip reports success while installing them
somewhere yt-dlp never reads. If you do not have Python, run
  winget install -e --id Python.Python.3.13
first.

Then reopen your terminal and check they respond:

  yt-dlp --version
  ffmpeg -version

If either is not found, install it manually and point the program at it under
File > Preferences > Locations.
